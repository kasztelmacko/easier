# Plan

Use this skill when the user wants to plan the next analysis steps.

## Instructions

1. Read `context/analysis_context.md`, `context/analysis_progress.md`, and `context/analysis_notes.md` when present.
2. Propose a short, ordered plan for the next analysis work.
3. Call out assumptions, data needs, and risks briefly.
4. Wait for confirmation before large implementation work.
