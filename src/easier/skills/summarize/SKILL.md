# Summarize

Use this skill when the user wants a concise status summary of the analysis.

## Instructions

1. Read `context/analysis_context.md`, `context/analysis_progress.md`, and `context/analysis_notes.md` when present.
2. Summarize what has been done, what was found, and what remains.
3. Keep the summary short and actionable.
4. Offer 1–3 concrete next steps.
